Plugin 01

Product Discovery Suite

Evaluate opportunities, define product requirements, and design user interaction.

  1. 11
    Opportunity Evaluator

    Evaluates new product opportunities through demand, channels and economics before committing to build.

  2. 12
    Product Requirements Builder

    Defines product requirements, business rules and acceptance criteria for a committed intent; edits product docs only.

  3. 13
    Interaction Design Builder

    Designs user flows, interaction states and mockups for a defined product scope; does not implement UI code.

2×

Plugin 02

Architecture Suite

Establish architecture drivers, document current systems, and design decisions and migrations.

  1. 21
    System Design Baseline Builder

    Defines measurable architecture drivers and constraints before system design; edits architecture docs only.

  2. 22
    Current Architecture Documenter

    Documents current architecture from implementation evidence; does not propose a target or audit fitness.

  3. 23
    System Design Proposal Builder

    Designs target system boundaries, contracts and tradeoffs from requirements; does not plan tasks or implement.

  4. 24
    Architecture Decision Recorder

    Records one architecture decision with alternatives, consequences and status; does not design the whole system.

  5. 25
    Architecture Diagram Builder

    Creates evidence-backed current or target architecture diagrams; not UI design.

  6. 26
    Architecture Migration Planner

    Plans architecture migrations with compatibility, data safety, rollout and recovery; does not execute them.

3×

Plugin 03

Delivery Planning Suite

Build delivery plans, select risk-based verification, and review readiness before implementation.

  1. 31
    Delivery Plan Builder

    Builds dependency-ordered delivery plans from requirements and repository evidence; read-only.

  2. 32
    Test Strategy Planner

    Plans risk-based test portfolios and acceptance evidence; does not write or execute tests.

  3. 33
    Plan Reviewer

    Reviews a concrete implementation plan for missing decisions, feasibility and risk before execution; read-only.

4×

Plugin 04

Implementation Suite

Deliver scoped changes, dependency upgrades, modernization, and measured performance improvements.

  1. 41
    Surgical Change Implementer

    Implements one scoped feature or fix through the smallest complete solution; not upgrades or performance tuning.

  2. 42
    Dependency Upgrader

    Upgrades dependencies in reversible batches with version-specific compatibility and regression checks.

  3. 43
    Code Modernizer

    Modernizes a bounded capability to reduce demonstrated maintenance cost; not routine upgrades or performance tuning.

  4. 44
    Performance Optimizer

    Profiles and improves a measured performance bottleneck; retains only verified improvements.

  5. 45
    Benchmark Comparator

    Compares tools or implementations through controlled benchmarks and independent correctness checks.

5×

Plugin 05

Quality Assurance Suite

Build acceptance tests and review deliveries, documentation, code, tests, architecture, and persistence.

  1. 51
    Acceptance Test Builder

    Builds, updates or retires scoped acceptance tests and verifies execution; does not repair product code.

  2. 52
    Delivery Reviewer

    Reviews a completed change for acceptance, regressions and release risk; read-only, not a whole-codebase audit.

  3. 53
    Documentation Auditor

    Audits documentation and comments for trust, coverage, consistency and freshness; read-only.

  4. 54
    Codebase Auditor

    Audits cross-cutting codebase health, security and maintainability; not a single-change review or specialist audit.

  5. 55
    Test Suite Auditor

    Audits existing tests for risk coverage, reliable oracles and maintenance value; does not edit tests.

  6. 56
    Architecture Auditor

    Audits implemented architecture boundaries, dependencies and ownership; not target design or plan review.

  7. 57
    Persistence Auditor

    Audits queries, transactions, consistency and persistence resource lifetimes; read-only.

6×

Plugin 06

Delivery Suite

Publish repositories and releases, prepare and execute deployments, and announce approved results.

  1. 61
    Repository Publisher

    Commits, pushes and remotely verifies authorized repository changes; does not create releases.

  2. 62
    Release Publisher

    Prepares and publishes an explicitly requested tagged GitHub release; does not deploy applications.

  3. 63
    Deployment Engineer

    Prepares CI/CD and infrastructure, then executes authorized deployments with health and recovery checks.

  4. 64
    Community Announcer

    Drafts or publishes authorized, fact-checked GitHub Discussions announcements; does not create releases.

Plugin 07

Operations Suite

Investigate operational deviations and evaluate observed product outcomes without changing live systems.

  1. 71
    Operations Investigator

    Diagnoses incidents from operational evidence and proposes recovery; does not change live systems.

  2. 72
    Product Outcome Evaluator

    Evaluates observed product outcomes against a prior hypothesis; does not run experiments or change user treatment.

Plugin 08

Skill Maintenance Suite

Review standalone skills, instruction boundaries, evidence contracts, and distribution integrity.

  1. 81
    Skill Reviewer

    Reviews skill instructions, trigger boundaries and distribution contracts; not product code.
