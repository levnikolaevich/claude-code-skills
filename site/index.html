Coming from v1?

Less machinery.
More useful memory.

Skills v2 retains the domain knowledge models benefit from being reminded about, and removes the framework they no longer need.

What moved

Plan and code review became review-suite. Focused audit, optimization, testing, and opportunity evaluation live in their own small suites.

What stopped

agile-workflow, documentation-pipeline, project-bootstrap, community-engagement, and setup-environment are retired.

What to do

Update the marketplace, install the v2 plugins you want, and start a new session. Existing cached v1 plugins are not removed automatically.

MCP retirement notice

Native host tools won.

Every published version of hex-line-mcp, hex-graph-mcp, hex-research-mcp, and hex-ssh-mcp is deprecated on npm. Their source and publishing infrastructure have been removed. There will be no updates or support; do not use them for new Skills v2 workflows.
